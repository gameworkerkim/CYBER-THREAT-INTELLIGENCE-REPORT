## 2. 핵심 차별화 요소 (3가지)

### 2-1. 권한 검증 게이트 (Authorization Gate)

대부분의 침투 도구는 "사용자가 스스로 권한을 지켜라"는 경고에 의존합니다. Heimdallr 는 **기술적으로 권한을 강제**합니다.

- **도메인 소유권 증명**: 대상 도메인의 서브 디렉터리에 난독화 토큰을 배치 → HTTP 로 확인(Google Search Console / Let's Encrypt HTTP-01 방식).
- **도메인 기반 이메일**: 요청자의 이메일이 대상 도메인 소속이어야 함. **무료 이메일(gmail·naver·daum·kakao 등) 도메인은 테스트 대상에서 배제**.
- **24시간 한정**: 검증 성공 후 24시간만 허용, 만료 시 재검증.

> 효과: "내 도메인 + 내 도메인 메일 + 내 서브 디렉터리"라는 **삼중 소유 신호**가 남아, 무단 타깃팅이 구조적으로 어려워집니다. 이는 단순 고지가 아니라 **제품 레벨의 안전장치**입니다.

### 2-2. CyberSecurityWiki — 지식의 축적과 재사용

기존 도구는 "한 번 실행하고 리포트를 버리는" 구조입니다. Heimdallr 는 매 실행의 산출물을 **기계가 읽을 수 있는 지식**으로 환원합니다.

- 공격 기법·탐지 규칙·하드닝 체크리스트를 **구조화된 위키**로 축적.
- **`llms.txt` + MCP server + REST API** 로 외부 LLM·MCP 가 직접 참조 가능.
- ARTEX 의 Sigma/Suricata/MISP 탐지 자산을 **살아있는 지식 그래프**로 승격.

> 효과: Heimdallr 를 쓰면 쓸수록 **방어 지식이 스스로 성장**합니다. 다른 AI 에이전트도 이 위키를 참조해 공격·방어 노하우를 재사용할 수 있습니다.

### 2-3. Cloudflare 프리티어 네이티브 + BYOK

- **무료로 돌아가는 웹 SaaS**: Next.js(Cloudflare Pages/Workers) + Neon(무료 PostgreSQL) + KV/D1/R2.
- **BYOK(Bring Your Own Key)**: 사용자가 자신의 LLM 키를 넣고 사용 → **플랫폼은 토큰 비용을 부담하지 않으므로** 무료 운영이 지속 가능.
- **Node.js/TypeScript**: Cloudflare 에지와 MCP/LLM 생태계에 네이티브.

> 효과: "설치 없이 브라우저에서 바로" 쓰면서도, 운영자가 토큰 비용을 대신 내지 않아 **프리티어 지속 가능성**이 확보됩니다.

## 3. 타 도구와의 세부 비교

### 3-1. ARTEX (원본) vs Heimdallr

| 항목 | ARTEX | Heimdallr |
|---|---|---|
| 언어 | Go | Node.js (TypeScript) |
| 배포 | 로컬/서버 바이너리 | Cloudflare 에지 SaaS |
| DB | 자체 PostgreSQL | Neon(서버리스) |
| 사용자 | 보안 전문가(설치·운영 가능) | 일반 사용자(브라우저) |
| 권한 검증 | 없음 | 도메인 토큰 + 도메인 이메일 + 24h |
| 지식 산출 | 정적 리포트·탐지 규칙 | 동적 Wiki + llms.txt/MCP |
| 목적 | 자율 침투 프레임워크 | 방어 중심 + 검증된 실험 + 지식 축적 |

### 3-2. 규칙 기반 스캐너 vs Heimdallr

- 스캐너는 **알려진 시그니처**만 탐지 → 제로데이·신규 기법·복합 공격 체인에 약함.
- Heimdallr 의 LLM 에이전트는 **상황을 판단해 다음 단계를 스스로 결정** → 다단계 체인·커스텀 로직 탐색 가능.
- 단, 스캐너의 **결정론적·재현 가능한** 장점은 유지 필요 → Heimdallr 는 "규칙 + LLM" 하이브리드 탐지로 보완.

### 3-3. PentestGPT / RAI / HackSynth / Enigma vs Heimdallr

- 이들은 대부분 **연구·실험 중심**의 로컬 도구로, 권한 검증·지식 축적·SaaS 운영 경험이 없음.
- Heimdallr 는 **제품 레벨의 가드레일 + 지식 환원 + 무료 운영**을 한 번에 제공.

## 4. Heimdallr 만의 "방어자 가치"

| 방어자 니즈 | Heimdallr 제공 |
|---|---|
| "자율 AI 공격이 어떻게 들어오는지 알고 싶다" | 검증된 범위 안에서 실제 공격 체인을 재현·관찰 |
| "내 시스템이 왜 뚫리는지 보고 싶다" | 탐지 규칙 + 하드닝 체크리스트가 포함된 방어자 보고서 |
| "탐지 규칙을 바로 쓰고 싶다" | Wiki 에서 Sigma/Suricata/MISP 규칙을 즉시 재사용 |
| "조직의 지식을 축적하고 싶다" | CyberSecurityWiki 로 팀·에이전트 간 노하우 공유 |

## 5. 요약

Heimdallr 의 차별화는 한 문장으로:

> **"자율 AI 침투를 '검증된 소유자에게만' 허락하고, 그 결과를 '재사용 가능한 방어 지식'으로 환원하는 Cloudflare 프리티어 SaaS."**

- ARTEX 의 자율성은 유지하되, **오남용을 구조적으로 차단**(권한 검증 게이트).
- 기존 도구가 버리는 실행 산출물을 **지식으로 축적**(CyberSecurityWiki).
- **무료 운영 가능**(Cloudflare + Neon + BYOK)한 배포 모델.
